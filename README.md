# 나혼자산다

시흥시 1인 가구를 위한 도시선정 의사결정지원 웹사이트입니다.

시흥시 1인 가구가 중요하게 생각하는 생활 인프라를 고르면, 6개 행정동의 조건 충족 여부를 비교하고 적합한 동네를 추천하는 데이터 시각화 웹 서비스입니다.

## 구현된 기능

- 음식점, 카페, 코인세탁방, 편의점, 마트, 지하철역, 버스정류장, 공원·러닝, 병원, 약국, 착한가격업소 다중 선택
- 선택 조건 순서를 직접 조정하는 우선순위 편집과 우선순위 기반 추천
- 배곧·정왕·오이도·신천·은행·대야권 러닝코스 6종 추천과 지도 선 시각화
- 도보 5분(약 330m), 10분(약 670m), 15분(약 1km) 범위 선택
- 가중치 없이 `충족 조건 수 / 선택 조건 수`로 추천 순위 계산
- 행정동 단계구분도, 선택 시설 마커, 추천 TOP 3 동시 갱신
- 행정동별 충족·미충족 조건, 교통 접근성, 평균 주거비, 시설 목록 표시
- 네이버 지도 길찾기와 네이버부동산 외부 연결
- 모바일·태블릿·데스크톱 반응형 레이아웃

## 데이터

`scripts/build_life_fit_data.py`가 제공된 `siheung_life_infra.csv`와 `행정안전부_착한가격업소 현황_20260630.csv`를 읽어 배포용 `data/processed/life_fit.json`을 만듭니다. 원본 CSV는 수정하지 않습니다.

```bash
python3 scripts/build_life_fit_data.py
```

생활시설은 제공된 카카오 장소 수집본을 사용합니다. 착한가격업소 원본의 시흥시 68개 레코드는 모두 정제 데이터에 보존하고, 현재 6개 비교지역과 주소가 매칭되는 25개는 지도·추천·메뉴 가격 카드에 반영합니다. 주거비와 버스 접근성은 UI·추천 흐름 검증을 위한 프로토타입 요약값이므로 실제 서비스 배포 전 공공데이터 집계로 교체해야 합니다.

러닝코스는 시흥시 공식 자료에 등장하는 배곧 해안로·오이도 공원과 제공된 공원 시설 좌표를 바탕으로 만든 MVP 추천 동선입니다. 현재 선형과 거리는 실제 도로 경로 API 결과가 아니므로, 출발 전 지도와 현장 보행 가능 여부를 확인해야 합니다. 향후 네이버 지도 API 연결 시 `running_routes[].coordinates`를 `naver.maps.Polyline`에 그대로 사용할 수 있습니다.

## 로컬 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 상태 확인은 `http://127.0.0.1:8000/health`, 데이터 API는 `http://127.0.0.1:8000/api/life-fit`입니다.

## 프로젝트 구조

```text
app/main.py                         FastAPI 서버와 API
static/index.html                   페이지 구조
static/css/style.css                반응형 디자인
static/js/app.js                    추천·필터·지도 상호작용
scripts/build_life_fit_data.py      원본 시설 CSV 정제
data/processed/life_fit.json        브라우저용 정제 데이터
static/data/siheung_dong_boundaries.geojson  행정동 경계 참고 데이터
```

## 추천 계산 원칙

각 카테고리는 문서에 정의된 최소 시설 수를 따로 사용합니다. 사용자가 지정한 1순위 조건부터 충족 여부를 차례로 비교하고, 결과가 같으면 전체 충족 조건 수와 선택 시설의 추정 개수를 적용합니다. 도보권 내 주요 시설도 같은 우선순위로 묶어 카테고리별 최대 3곳을 보여줍니다. 서로 다른 시설 개수를 하나의 불투명한 점수로 합산하지 않습니다.
