← 홈으로 돌아가기
01

무엇을 도와드리나요?

생활 인프라 조건에 따라 시흥시 동네를 비교하고, 사용자가 선택한 주소 주변의 생활시설과 교통 접근성을 별도로 확인할 수 있습니다.

02

결과는 어떻게 보아야 하나요?

추천 결과는 현재 확보한 공공·공개 데이터의 등록 시설 수를 비교한 탐색용 정보입니다. 실제 보행로, 운영 여부와 부동산 계약 조건은 현장에서 다시 확인해 주세요.

03

주소와 교통정보

교통정보는 동네 추천 점수에 포함되지 않습니다. 정확한 주소를 선택했을 때만 행정구역 경계와 관계없이 주변 지하철역과 버스정류장을 보여드립니다.

KEY

주소·교통 API 연결

카카오 개발자 앱의 REST API 키를 입력하면 정확한 주소 좌표와 주변 교통정보를 불러옵니다. 키는 현재 브라우저 탭에만 저장되며 Git에는 포함되지 않습니다.
