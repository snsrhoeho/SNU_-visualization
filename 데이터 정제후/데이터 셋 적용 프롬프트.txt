최종 취합 CSV 홈페이지 반영 요청
이번 작업에서는 데이터최종취합 브랜치의 데이터 정제후 폴더 안에 있는 CSV 파일만 최종 데이터로 사용해주세요.
해당 브랜치의 다른 폴더 및 기존 CSV는 이번 데이터 반영 대상에서 제외해주세요. 기존 홈페이지에 사용 중인 CSV가 있더라도 이번에는 데이터 정제후 폴더의 CSV로 교체하여 반영해주세요.
작업 대상 데이터 경로: 데이터최종취합 브랜치 / 데이터 정제후 /
이 폴더 외부의 CSV를 새 데이터 소스로 추가하거나, 기존 CSV와 혼합해서 사용하지 마세요.
먼저 해당 폴더에 실제로 존재하는 CSV 목록과 각 파일의 컬럼을 확인한 뒤 작업해주세요.
기존 홈페이지에는 현재와 다른 데이터 및 유형 체계가 적용되어 있을 수 있습니다. 기존 CSV 대신 이번에 최종 취합한 CSV를 사용하고, 홈페이지의 카테고리 및 유형이 아래 최종 체계로 반영되도록 수정해주세요.
1. 최종 카테고리 체계
홈페이지에서는 최종적으로 다음 구조로 데이터가 분류되고 표시되도록 해주세요.
1. 휴식·운동
   ├ 공원
   ├ 놀이터
   └ 헬스장

2. 쇼핑·유통
   ├ 대형마트
   ├ 소형마트
   ├ 식자재마트
   └ 편의점

3. 의료·건강
   ├ 병원
   │  ├ 내과
   │  ├ 치과
   │  ├ 정형외과
   │  ├ 산부인과
   │  ├ 피부과
   │  ├ 24시 병원
   │  └ 기타
   ├ 약국
   └ 보건소

4. 반려동물
   ├ 동물병원
   └ 반려동물시설

5. 음식점
   ├ 한식
   ├ 아시안
   ├ 양식
   ├ 기타
   ├ 주점
   └ 치킨
      + 착한가격업소 여부(속성)

   ├ 일반카페
   └ 테마카페
      + 착한가격업소 여부(속성)

7. 생활편의
   ├ 코인세탁방
   └ 목욕탕

8. 문화
   ├ 관람시설
   └ 도서관

9. 치안·안전
   ├ 방범 CCTV
   ├ 경찰서·파출소·지구대
   ├ 소방서
   ├ 안전비상벨
   ├ 민방위대피시설
   └ 어린이보호구역

10. 교육
    ├ 초등학교
    ├ 중학교

위 체계를 이번 홈페이지 데이터 반영의 최종 기준으로 사용해주세요.
기존 홈페이지의 유형명이나 분류 방식이 위 체계와 다르다면, 기존 분류에 새 CSV를 맞추는 것이 아니라 위 최종 체계가 홈페이지에 반영되도록 수정해주세요.
2. 사용할 데이터
이번에 최종 취합 및 정제된 CSV들을 홈페이지의 기준 데이터로 사용해주세요.
기존 홈페이지에서 사용하던 CSV와 이번 최종 CSV를 함께 사용하지 말고, 이번 최종 CSV로 교체하여 데이터가 중복되지 않도록 해주세요.
새로운 데이터를 추가로 수집할 필요는 없습니다.
각 CSV의 실제 컬럼과 내용을 확인한 후 위 카테고리 체계에 맞게 반영해주세요.
3. 항목별 반영 시 주의사항
의료·건강
병원 CSV에는 최종 세부분류가 적용되어 있습니다.
병원은 다음 분류가 홈페이지에서도 그대로 반영되도록 해주세요.

기타
이미 CSV에 분류된 값을 기준으로 사용하고 홈페이지에서 별도의 기준으로 다시 분류하지 않아도 됩니다.
반려동물
반려동물시설 CSV에는 펫미용과 애완동물 배변봉투함 등이 포함되어 있지만 홈페이지에서는 별도로 나누지 않고 모두 **반려동물시설**로 표시해주세요.
즉 홈페이지에서는:
반려동물
├ 동물병원
└ 반려동물시설
까지만 구분하면 됩니다.
음식점
음식점 CSV의 최종 세부분류를 기준으로 다음 유형이 반영되도록 해주세요.
한식
아시안
양식
기타
주점
치킨
음식점 CSV에 착한가격업소 여부에 해당하는 값이 있으며, 값이 1인 시설에는 홈페이지에서도 착한가격업소라는 속성이 반영되도록 해주세요.
착한가격업소는 별도의 음식점 유형으로 만들지 않습니다.
예:
음식점 > 한식
+ 착한가격업소
카페
카페 CSV의 최종 세부분류를 기준으로:
일반카페
테마카페
가 홈페이지에 반영되도록 해주세요.
음식점과 마찬가지로 착한가격업소 여부 값이 1인 카페에는 착한가격업소 속성이 추가로 반영되도록 해주세요.
착한가격업소는 별도의 카페 유형으로 만들지 않습니다.
문화
관람시설 CSV에는 공연장과 영화관이 포함되어 있지만 홈페이지에서는 이를 별도로 구분하지 않고 모두 **관람시설**로 표시해주세요.
즉:
문화
├ 관람시설
└ 도서관
까지만 구분하면 됩니다.
나머지 카테고리
휴식·운동, 쇼핑·유통, 생활편의, 치안·안전, 교육은 위 최종 카테고리 체계에 맞춰 각 최종 CSV가 해당 유형으로 정상 반영되도록 해주세요.

휴식·운동 최신 파일 기준
- `1-2. 놀이터.csv`를 놀이터 데이터로 사용해주세요. 기존의 “놀이체험시설” 명칭은 홈페이지와 코드에서 사용하지 않습니다.
- `1-3. 헬스장.csv`에는 기존 체육시설과 헬스장 데이터가 통합되어 있습니다. 이 파일 전체를 “헬스장”으로 표시해주세요.
- 이전의 `1-3. 체육시설.csv`와 `1-4. 헬스장.csv`를 별도로 읽거나 중복 반영하지 마세요.

카페 최신 분류 기준
- 카페 CSV의 `세부분류` 값은 `일반카페`와 `테마카페`만 사용합니다.
- 이전에 `기타`였던 값은 최종 CSV에서 모두 `테마카페`로 수정되었습니다.
- 홈페이지에서 `기타` 카페 유형을 만들거나 다시 분류하지 말고 CSV의 최종 값을 그대로 사용해주세요.

경찰관서 좌표 반영
- `9_siheung_경찰관서.csv`에는 주소를 기준으로 확인한 `위도`, `경도` 컬럼이 있습니다.
- 경찰서·지구대·파출소는 행정구역 중심점이 아니라 각 행의 위도·경도를 사용해 개별 점 마커로 표시해주세요.
- `위도`는 latitude, `경도`는 longitude로 연결하며 순서를 바꾸지 마세요.

CCTV 지도 표시 수정
- `9_siheung_CCTV.csv`에는 각 CCTV의 `WGS84위도`, `WGS84경도`가 있으므로 모든 CCTV를 실제 좌표 기반의 점 데이터로 처리해주세요.
- CCTV를 행정동·생활권 단위의 원, 반경, 밀집도 구역 또는 폴리곤 음영으로 대체하지 마세요.
- 기존 코드에서 CCTV에 `density_only`, `aggregate_only` 또는 이와 유사한 구역 집계 전용 설정이 적용되어 있다면 제거하거나 `false`로 바꾸고, 지도 마커가 표시되도록 `map_visible`을 활성화해주세요.
- 지도 확대 수준이 낮아 2,000여 개 점이 겹치거나 느려질 경우에는 점 마커 클러스터링을 사용할 수 있습니다. 다만 클러스터도 개별 좌표를 바탕으로 해야 하며, 확대하면 실제 CCTV 점들이 나타나야 합니다.
- CCTV 마커 클릭 시 가능하면 설치목적, 주소, 카메라대수 등 해당 CSV 행의 정보를 보여주세요.

최종 검증 기준
- 휴식·운동 필터에는 공원, 놀이터, 헬스장만 나타나야 합니다.
- 카페 필터에는 일반카페와 테마카페만 나타나야 하며 기타는 없어야 합니다.
- 경찰관서와 CCTV는 모두 각 CSV의 위도·경도에 따라 개별 점 또는 좌표 기반 클러스터로 표시되어야 합니다.
- 삭제된 이전 파일명이나 기존 데이터 소스를 코드에서 계속 참조하지 않는지 확인해주세요.
- 데이터 정제후 폴더의 같은 장소가 중복 표시되지 않는지 확인해주세요.
4. 반영 시 기본 원칙
이번에 최종 취합된 CSV를 기준으로 사용해주세요.
기존 CSV와 최종 CSV가 함께 반영되어 중복되지 않도록 해주세요.
각 CSV의 실제 컬럼명을 확인해서 홈페이지에 연결해주세요.
최종 CSV에 이미 적용된 분류 및 정제 결과를 우선해주세요.
새로운 데이터를 추가로 수집하거나 임의로 데이터를 만들어 넣지 마세요.
홈페이지 구현 방식은 현재 프로젝트 구조에 적절한 방식으로 처리해주세요.
현재 홈페이지 구조 때문에 위 분류체계를 그대로 반영하기 어려운 부분이 있거나, CSV에서 필요한 값을 확인할 수 없는 경우 임의로 판단하지 말고 해당 부분을 알려주세요.
