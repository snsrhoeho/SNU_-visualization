> 이 문서는 `snsrhoeho`가 실제 반영 여부를 검토·커밋하기 위한 **참고 자료**입니다.
> 이 브랜치의 다른 파일(커밋은 하지 않음)과 함께 검토해 주세요.
>
> 조사 범위: **경기데이터드림(data.gg.go.kr)**, **경기도로 한정하지 않고 시흥시만** 필터링.
> 공공데이터포털(data.go.kr)은 별도 활용신청이 필요해 이번 1차 조사에서는 후순위로 뒀습니다.

## 왜 이 목록인가

`분석_보고서_1인가구.md`가 제안한 3개 업종(코인세탁소·코인노래방·트레이닝장)에 더해,
"1인가구에 필요한 시설이 저것뿐인가?"라는 질문에서 출발해 세탁·놀이·운동·상권인증·자연·문화·
먹거리·의료·안전 8개 생활 영역으로 범위를 넓혀 경기데이터드림에서 실제 존재를 확인한
데이터셋만 정리했습니다. (존재하지 않는 것으로 확인된 검색어: 만화카페·방탈출, 무인매장,
작은도서관 단독 데이터셋, 1인가구 지원센터 단독 데이터셋, 청년센터, 당구장/볼링장/스크린골프
단독 데이터셋)

## 접근 방식과 한계 (중요)

- 경기데이터드림 검색·상세 페이지는 **자바스크립트로 결과를 그리는 SPA**라서, 자동 크롤링
  도구(WebFetch)로는 실제 행 데이터(상호명·주소·좌표)나 Open API 요청 URL을 읽어올 수 없었습니다.
  (227페이지 목록도 같은 이유로 기계적으로 페이지를 넘기며 훑는 것이 불가능해, 검색엔진 색인을
  통한 키워드 스윕으로 대체했습니다.)
- 인증키 없이 Open API를 호출하면 **샘플 5건**만 반환됩니다. 전체 데이터를 받으려면 로그인 후
  "활용신청"(자동승인)이 필요합니다.
- 이번 조사에서 사용자가 발급받은 키(`ea512c98e7f749d8810c3ba5c5e33eed`, `.env`의
  `GG_DATA_SERVICE_KEY`)로 실제 호출을 시도했지만, **정확한 Open API 요청 URL(Endpoint)을
  아직 확인하지 못했습니다** — 이 정보는 로그인한 브라우저 화면(Open API 탭)에만 표시되고,
  정적 크롤링으로는 노출되지 않았습니다. `scripts/collect_gg_infra_poi.py`에 TODO로 표시해
  두었으니, 로그인 화면에서 각 데이터셋의 "요청 URL"을 확인해 채워 넣으면 바로 동작합니다.
- 아래 표의 `infId`는 경기데이터드림 상세 페이지 URL의 `infId` 파라미터입니다. 상세 페이지:
  `https://data.gg.go.kr/portal/data/service/selectServicePage.do?infId={infId}&infSeq=1`
  (`infSeq=3`이면 Open API 탭)

6개 동 레이아웃 밖의 장곡동 권역과 겹칠 수 있음 — 동 경계 폴리곤과 대조 필요).

## 확인됐지만 시흥시 데이터가 없을 가능성이 있는 것

- **전국안심택배함표준데이터**(`data.go.kr/data/15034534/standard.do`, 로그인 불필요 다운로드)는
  미리보기에 파주·용인·수원·안양·성남 등은 보였지만 **시흥시는 보이지 않았습니다** — 시흥시가
  이 특정 전국 표준데이터셋에 등록하지 않았을 가능성이 있습니다. 안심택배함은 경기데이터드림의
  "여성안심무인택배함 현황"(위 표, 경기도 31개 시군 전체 포함이라고 명시됨) 쪽이 더 신뢰할 만합니다.

## 다음 단계 제안

1. 경기데이터드림에 로그인한 화면에서 세탁업/노래연습장업/체력단련장업/안심택배함 각 데이터셋의
   "Open API" 탭 → 요청 URL(Endpoint)을 복사해 `scripts/collect_gg_infra_poi.py`의 TODO에 채워 넣기.
2. 위 4개 카테고리부터 실제 호출 → 시흥시로 필터 → `data/raw/infra_poi/`에 저장.
3. `scripts/build_infra_dashboard_data.py` 실행해 `data/processed/infra_dashboard.json` 정식본 생성.
4. 캠핑장 4곳은 이미 확보된 실제 데이터이므로 지오코딩만 하면 바로 반영 가능.
